## The Agents: Codex, ChatGPT Work, and Dots

An agent's harness is the program around the model that lets it act: it reads files, runs commands, and asks your permission where it matters. OpenAI offers three. Codex works directly in a folder on your computer, or on OpenAI's computers through Codex Cloud; ChatGPT Work takes a task and returns finished files; dots are always-on agents that keep working between conversations. [AI Agents](../agents.md) explains agents in general, and [Your First Agent Session](../first-session.md) walks through a first task.

## Commands, with Worked Examples

In Codex you type a command starting with a slash, such as `/plan`, in the same box as your requests; a few, such as `codex doctor`, are typed in the terminal instead. Many commands work both in the Codex CLI and in the Codex view of the ChatGPT desktop app; where a command works in only one place, or differs between them, its description says so. Every command a student, faculty member or staff member is likely to use has a worked example below, grouped by what it helps with: a small, realistic situation, what you type, and what you then see, drawn from OpenAI's documentation. Commands that only a software developer would need are listed at the end, without examples.
