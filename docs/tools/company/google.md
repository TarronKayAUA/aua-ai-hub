## The Agents: Antigravity, Gemini Spark, and More

An agent's harness is the program around the model that lets it act: it reads files, runs commands, and asks your permission where it matters. Google's agent for work that lives in files is Google Antigravity, which comes as a terminal tool (the Antigravity CLI), a desktop app (Antigravity 2.0) and a code editor, all built on one shared agent; the terminal tool and the desktop app also share their settings. Gemini Spark is the agent inside the Gemini app, for multi-step personal tasks. In June 2026 Google moved individual users from its earlier Gemini CLI to the Antigravity CLI, so Gemini CLI appears below only briefly, beside Jules, Google's coding agent for GitHub. [AI Agents](../agents.md) explains agents in general, and [Your First Agent Session](../first-session.md) walks through a first task.

## Commands, with Worked Examples

In the Antigravity CLI you type a command starting with a slash, such as `/plan`, in the same box as your requests; the commands in Google's slash command catalog, such as `/goal` and `/schedule`, also work in the Antigravity 2.0 app. Every command a student, faculty member or staff member is likely to use has a worked example below, grouped by what it helps with: a small, realistic situation, what you type, and what you then see, drawn from Google's documentation. The rest, mostly for software developers, are listed at the end. The Gemini app itself has no commands of this kind: there, `/` calls one of your skills and `@` chooses a connected app, as the symbols table below shows.
