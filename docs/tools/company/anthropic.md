## The Agents: Claude Code and Cowork

An agent's harness is the program around the model that lets it act: it reads files, runs commands, and asks your permission where it matters. Anthropic offers two. Claude Code works directly in a folder on your computer; Cowork takes office tasks and returns finished files. [AI Agents](../agents.md) explains agents in general, and [Your First Agent Session](../first-session.md) walks through a first task.
